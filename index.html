Install as an app

Android / Chrome: tap Install in the top bar, or open the browser menu and choose Install app.

iPhone / iPad: tap Share, then Add to Home Screen.

Desktop: look for the install icon at the right end of the address bar.

Installed, it opens full screen, works offline, and picks up updates the next time you open it.

Tips

Hold Compare to peek at the original image at any time.

Drag the panel edge (desktop) to widen the tools, or hide them entirely with the sliders button in the top bar.

Double-click a slider label to reset that single control.

Privacy & security

Fully offline. Every edit runs in your browser — your images are never uploaded. The page is locked down with a strict Content-Security-Policy that blocks outbound connections, plugins and framing.
